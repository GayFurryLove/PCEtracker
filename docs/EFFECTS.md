# Эффекты и инструменты

Всё ниже исполняется плеером раз в тик (кадр 60 Гц) и сводится к записям в регистры
PSG — то есть физически возможно на консоли и будет работать в экспорте HES/ROM.

Тик 0 — строка паттерна прочитана; «слайды» работают на остальных тиках строки (как в ProTracker).
Строка длится `speed` тиков при темпе 150; другой темп растягивает или сжимает её (`Fxx`, ниже).
Высота тона везде в **единицах периода** чипа (12 бит): чем меньше период, тем выше нота.
Поэтому слайды и вибрато на низких нотах звучат мягче, на высоких — сильнее, как на железе.

## Колонки строки

`C-4 00 1F 422 ...` — нота, инструмент (hex), громкость `00-1F` (5 бит), два эффекта.
Ноты `C-1`…`B-8`, `OFF` — отпускание (release макросов; без release — тишина).

## Как набирать эффект

В колонке команды нажмите букву/цифру команды — курсор **останется на той же строке** и
перейдёт на первую цифру параметра; две hex-цифры — и курсор вернётся в колонку команды
на строку ниже (шаг `F5/F6`). Пример: `F` `0` `6` → `F06`. Пока курсор стоит в колонке
эффекта, строка состояния внизу пишет, что делает эффект под курсором.

## Команды

**Д** — действует, пока не изменят (на следующих строках и нотах тоже), **С** — только эта строка.

| Команда | Действие | Регистры |
|---|---|---|
| `0xy` | **Д** арпеджио: нота, +x, +y полутонов, шаг на каждый тик (скорость — `Exx`). Работает и дальше, **через строки и новые ноты, пока не встретится `000`**. Новая нота начинает аккорд с основной ноты. `0x0` — две ноты (основная и +x) | период |
| `Exx` | **Д** скорость арпеджио: xx тиков на шаг (`E01` — каждый тик, по умолчанию; `E00` = `E01`) | — |
| `1xx` | **С** слайд вверх: период −xx за тик | период |
| `2xx` | **С** слайд вниз: период +xx за тик | период |
| `3xx` | **С** портаменто к ноте со скоростью xx (00 = прежняя) | период |
| `4xy` | **С** вибрато: x скорость, y глубина (синус 32 шага) | период |
| `8xy` | **Д** панорама: x левый, y правый (по 4 бита) | `$0805` |
| `Axy` | **С** громкость: +x или −y за тик | `$0804` |
| `Bxx` | переход на позицию ордера xx | — |
| `Cxx` | **С** обрезать ноту на тике xx | `$0804` |
| `Dxx` | конец паттерна, перейти на строку xx следующего | — |
| `Fxx` | **Д** `01`–`1F`: скорость, тиков на строку. `20`–`FE`: темп (150 = `F96` — норма); строка = скорость × 150 / темп тиков, дробная часть копится, так что средний темп точный. **`F00` или `FFF` — остановить песню** (тишина; WAV, HES и ROM на этом заканчиваются, без петли) | — |
| `Gxy` | **Д** общая громкость: x левый, y правый | `$0801` |
| `Lxx` | LFO: 00 выкл, 01-03 глубина, +80 сброс/стоп | `$0809` |
| `Mxx` | частота LFO | `$0808` |
| `Nxx` | шум (только каналы 5-6): 00 выкл, 01-20 вкл, частота xx-1 | `$0807` |
| `Pxx` | **Д** расстройка: период + (xx − 80) | период |
| `Rxx` | **С** повторный запуск ноты каждые xx тиков | всё |
| `Wxx` | волна xx из банка волн песни — для текущей ноты. На строке с нотой заменяет волну инструмента для этой ноты; следующая нота снова берёт волну своего инструмента. Если у инструмента есть макрос `wave`, он перебивает `Wxx`. Номера только существующих волн (новые — `CTRL+W` на экране F10). Смена = перезапись памяти волны (щелчок) | `$0806` |

Все числа — hex. `Dxx` тоже hex (в ProTracker там десятичное — отличие намеренное).

### Чего нет и почему

- **Темп в BPM** — драйвер работает от кадрового прерывания 60 Гц; темп (`F20`–`FE`)
  меняет только то, сколько целых кадров длится строка. Таймер ~7 кГц нужен для DDA.
- **Тонкие слайды/огибающие быстрее кадра** — драйвер обновляет регистры раз в кадр.
- **Шум на каналах 1-4** — нет генератора: `Nxx` там игнорируется.
- **Смена волны без щелчка** — память волны пишется только при выключенном канале.
- **LFO на других каналах** — аппаратно только канал 2 модулирует канал 1.
  Канал 2 при этом продолжает звучать: глушите его громкостью или панорамой.

## Инструмент

- `wave` — волна по умолчанию, `volume` — громкость 00-1F.
- `resetphase` — перед каждой нотой волна начинается с отсчёта 0 (канал выкл/вкл).
- Макросы (одно значение на шаг, шаг длится `speed` тиков — по умолчанию 1;
  `loop` — точка петли, `release` — точка отпускания; как ставить — [INSTRUMENTS.md](INSTRUMENTS.md)):

| Макрос | Значения | Что делает |
|---|---|---|
| `vol` | 0…31 | громкость; складывается с громкостью канала как ослабление (шкала чипа логарифмическая) |
| `arp` | −96…96 | смещение в полутонах |
| `pitch` | −128…127 | добавка к периоду каждый тик (накапливается) |
| `wave` | номер волны | **модуляция волны**: последовательность волн; `speed` задаёт, сколько тиков звучит каждая (каждая смена = перезапись памяти волны) |
| `noise` | 0…32 | каналы 5-6: 0 выкл, n = шум с частотой n−1 |
| `pan` | 0…255 | панорама байтом `$LR` |

Петля без release крутится до конца ноты. С release — макрос держится в петле
(или на точке release), пока не придёт `OFF`, потом проигрывает остаток.
