# Эффекты и инструменты

Всё ниже исполняется плеером раз в тик (кадр 60 Гц) и сводится к записям в регистры
PSG — то есть физически возможно на консоли и будет работать в экспорте HES/ROM.

Тик 0 — строка паттерна прочитана; «слайды» работают на тиках 1…speed-1 (как в ProTracker).
Высота тона везде в **единицах периода** чипа (12 бит): чем меньше период, тем выше нота.
Поэтому слайды и вибрато на низких нотах звучат мягче, на высоких — сильнее, как на железе.

## Колонки строки

`C-4 00 1F 422 ...` — нота, инструмент (hex), громкость `00-1F` (5 бит), два эффекта.
Ноты `C-1`…`B-8`, `OFF` — отпускание (release макросов; без release — тишина).

## Команды

| Команда | Действие | Регистры |
|---|---|---|
| `0xy` | арпеджио: нота, +x, +y полутонов по тикам | период |
| `1xx` | слайд вверх: период −xx за тик | период |
| `2xx` | слайд вниз: период +xx за тик | период |
| `3xx` | портаменто к ноте со скоростью xx (00 = прежняя) | период |
| `4xy` | вибрато: x скорость, y глубина (синус 32 шага) | период |
| `8xy` | панорама: x левый, y правый (по 4 бита) | `$0805` |
| `Axy` | громкость: +x или −y за тик | `$0804` |
| `Bxx` | переход на позицию ордера xx | — |
| `Cxx` | обрезать ноту на тике xx | `$0804` |
| `Dxx` | конец паттерна, перейти на строку xx следующего | — |
| `Fxx` | скорость: xx тиков на строку (01-1F) | — |
| `Gxy` | общая громкость: x левый, y правый | `$0801` |
| `Lxx` | LFO: 00 выкл, 01-03 глубина, +80 сброс/стоп | `$0809` |
| `Mxx` | частота LFO | `$0808` |
| `Nxx` | шум (только каналы 5-6): 00 выкл, 01-20 вкл, частота xx-1 | `$0807` |
| `Pxx` | расстройка: период + (xx − 80) | период |
| `Rxx` | повторный запуск ноты каждые xx тиков | всё |
| `Wxx` | сменить волну на xx (перезапись памяти волны, щелчок) | `$0806` |

Все числа — hex. `Dxx` тоже hex (в ProTracker там десятичное — отличие намеренное).

### Чего нет и почему

- **Темп в BPM** — драйвер работает от кадрового прерывания 60 Гц; темп задаётся
  только числом тиков на строку (`Fxx`). Таймер ~7 кГц нужен для DDA, а не для темпа.
- **Тонкие слайды/огибающие быстрее кадра** — драйвер обновляет регистры раз в кадр.
- **Шум на каналах 1-4** — нет генератора: `Nxx` там игнорируется.
- **Смена волны без щелчка** — память волны пишется только при выключенном канале.
- **LFO на других каналах** — аппаратно только канал 2 модулирует канал 1.
  Канал 2 при этом продолжает звучать: глушите его громкостью или панорамой.

## Инструмент

- `wave` — волна по умолчанию, `volume` — громкость 00-1F.
- `resetphase` — перед каждой нотой волна начинается с отсчёта 0 (канал выкл/вкл).
- Макросы (одно значение на тик, `loop` — точка петли, `release` — точка отпускания):

| Макрос | Значения | Что делает |
|---|---|---|
| `vol` | 0…31 | громкость; складывается с громкостью канала как ослабление (шкала чипа логарифмическая) |
| `arp` | −96…96 | смещение в полутонах |
| `pitch` | −128…127 | добавка к периоду каждый тик (накапливается) |
| `wave` | номер волны | последовательность волн (каждая смена = перезапись памяти волны) |
| `noise` | 0…32 | каналы 5-6: 0 выкл, n = шум с частотой n−1 |
| `pan` | 0…255 | панорама байтом `$LR` |

Петля без release крутится до конца ноты. С release — макрос держится в петле
(или на точке release), пока не придёт `OFF`, потом проигрывает остаток.
