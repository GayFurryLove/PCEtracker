# Экспорт для PC Engine: HES

```bash
./build/pcet_render songs/demo.pcet demo.wav --hes demo.hes
```
или `CTRL+H` в окне трекера (файл рядом с песней).

## Статус проверки (читать обязательно)

| Проверка | Результат |
|---|---|
| Встроенная машина HuC6280 (`src/export/hes_machine.*`): HES исполняется, каждая запись в регистры PSG сравнивается с плеером трекера | ✔ выполняется **при каждом экспорте**; файл не записывается, если сверка не прошла |
| Сторонние эмуляторы (Mednafen и др.) | ✘ **ещё не проверено** |
| Настоящая консоль | ✘ **не проверено** |

Пока две последние строки не закрыты, совместимость с эмуляторами и железом **не заявляется**.
Встроенная машина написана тем же автором, что и драйвер, поэтому общая ошибка понимания
процессора теоретически может пройти незамеченной — для этого и нужна сторонняя проверка.

## Как это устроено

Экспортёр прогоняет песню через тот же `Player`, что звучит в трекере, и записывает по кадрам
все записи в регистры PSG. Драйвер на консоли:

- **VBlank (60 Гц)** — читает один кадр потока и выполняет записи в регистры.
  Поэтому любые эффекты и макросы трекера работают в экспорте без отдельной реализации:
  они уже «сведены» в поток.
- **Таймер (~6991 Гц)** — для каждого канала с DDA-семплом пишет очередное 5-битное значение
  и сдвигает позицию с шагом 8.8 (те же числа, что в трекере). Петли семплов и переходы
  через границы банков обрабатывает сам.

Поток: первый проход песни, затем повторяющийся проход и переход на его начало.
Экспортёр записывает и третий проход и сравнивает его со вторым: если они различаются
(песня «не зацикливается чисто»), об этом будет предупреждение.

### Образ

| Банк (8 КБ) | Содержимое |
|---|---|
| 0 (`$E000`) | драйвер (≈0.4 КБ кода), таблица волн `$F000`, таблицы семплов `$F800`, векторы `$FFF6` |
| 1…S | данные DDA-семплов (байт на значение) |
| S+1… | поток кадров |

Предел — 1 МБ (128 банков). Драйвер собирается встроенным мини-ассемблером
([driver6280.cpp](../src/export/driver6280.cpp)) — внешний ассемблер не нужен.

### Команды потока

| Байты | Действие |
|---|---|
| `00-09 vv` | записать `vv` в регистр PSG `$0800+n` |
| `10 ww` | загрузить волну `ww`: `$0804=$40`, `$0804=$00`, 32 × `$0806` |
| `20+c ss ll hh` | запустить DDA-семпл `ss` на канале `c` с шагом `hh.ll` |
| `28+c ll hh` | сменить шаг DDA |
| `30+c` | остановить DDA |
| `80+n` | конец кадра и ещё `n` кадров без команд |
| `FF ll hh bb` | продолжить с адреса `hh.ll` банка `bb` (петля) |

## Отличия от звучания в трекере

- Записи кадра выполняются не мгновенно, а за время работы обработчика (до ~1–2 мс на
  «тяжёлом» кадре с загрузкой волн). DDA-семпл стартует после записей своего кадра.
  На слух это неразличимо; регистры и их значения совпадают точно.
- Фаза таймера относительно VBlank на консоли не определена: обрезанная DDA-нота может
  отличаться на один отсчёт.

## Размер

Поток не сжимается, кроме пропуска пустых кадров и команды загрузки волны. Демо (12.8 с,
два прохода): 15.6 КБ потока. Вибрато на всех каналах даёт ≈20 байт на кадр.
Дедупликация одинаковых проходов и сжатие — возможное улучшение, если понадобится место.

## Послушать HES без эмулятора

```bash
./build/hes_play demo.hes out.wav --seconds 30
```
Исполняет HES на встроенной машине 6280 и пишет WAV. Понимает только инструкции,
которые использует драйвер PCEtracker — чужие HES, скорее всего, не запустятся.
