# Формат песни `.pcet` (версия 1)

Текстовый, читается и правится в любом редакторе, хорошо видно в diff.
Пример: [songs/demo.pcet](../songs/demo.pcet). `#` — комментарий.

```
PCETRACKER 1
title "Название"
author "Автор"
speed 6

wave 00 1F1F...00          # 32 отсчёта по 2 hex-цифры, 00-1F (5 бит)

instrument 00 "Lead"
  wave 01
  volume 1F
  resetphase               # необязательно
  macro vol loop 2 release 5 : 31 28 25 22 20 18 10 0
  macro arp loop 0 : 0 4 7
end

pattern 00 rows 32
00 C-4 00 1F 422 ... | --- -- -- ... ... | (6 каналов)
04 E-4 00 -- ... ... | ...
end

orders 00 01 00 02
```

- Номер строки в начале строки паттерна необязателен; пропущенные строки пустые.
- Ячейка: `нота инструмент громкость эффект эффект`, пустые поля: `---`, `--`, `...`.
- Сохранение всегда пишет все строки (полная сетка) — так проще читать.
- Ошибки загрузки указывают номер строки файла.

Проверить и привести файл к каноническому виду:

```bash
pcet_render song.pcet out.wav --resave song_clean.pcet
```
