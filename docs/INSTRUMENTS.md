# Экран инструмента (F10)

`F9` — паттерны, `F10` — инструмент. `TAB` переключает фокус: параметры → волна → макрос.
Клавиши нот на этом экране всегда проигрывают текущий инструмент (инструменты с шумовым
макросом — на канале 5, где шум существует).

## Параметры

| Поле | Значения | Клавиши |
|---|---|---|
| NAME | имя (ASCII) | ENTER — ввод, ENTER/ESC — готово/отмена |
| TYPE | WAVETABLE / DDA SAMPLE | ENTER или ←/→ |
| WAVE | номер волны из банка | ←/→ (SHIFT ×16) |
| SAMPLE | номер DDA-семпла | ←/→ |
| VOLUME | 00-1F | ←/→ |
| PHASE | FREE RUNNING / RESET ON NOTE | ENTER |

`CTRL+N` новый инструмент, `CTRL+D` копия, `CTRL+W` новая волна (копия текущей),
`CTRL+T` название песни. Всё это отменяется `CTRL+Z`.

## Волна — 32 отсчёта × 5 бит

Ровно то, что лежит в памяти волны канала. ←/→ отсчёт, ↑/↓ значение (SHIFT ±4),
PGUP/PGDN — другая волна. Мышью можно рисовать.
`ALT+1…9`: синус, меандр, пила, треугольник, шум, очистить, инверсия, сдвиг фазы, половина амплитуды.

## Макросы

Одно значение на шаг. Шаг длится **SPD** тиков (по умолчанию 1 тик = 1/60 с):
`ALT+←/→` на фокусе макроса меняет SPD (1–64). ←/→ шаг, ↑/↓ значение (SHIFT ±8),
INS/DEL вставить/удалить шаг, `ALT+C` очистить, PGUP/PGDN — другой макрос
(VOLUME, ARPEGGIO, PITCH, WAVE, NOISE, PAN). Мышью можно рисовать.
Подробно о смысле значений — [EFFECTS.md](EFFECTS.md).

### Петля (loop) — как сделать

1. `TAB` до фокуса макроса, `PGUP/PGDN` — выбрать макрос.
2. Нарисуйте шаги мышью или стрелками (↑/↓ задаёт значение, → — следующий шаг).
3. Поставьте курсор (←/→) на шаг, **с которого** должна начинаться петля, и нажмите `ALT+L`.
   Под шагом появится `L`, зацикленная часть станет яркой, в списке макросов — `loop 02`.
4. Дойдя до последнего шага, макрос прыгает обратно на `L` и крутится, пока звучит нота.
   `ALT+L` на том же шаге ещё раз — убрать петлю.

**Release:** `ALT+R` на шаге ставит `R`. Пока нота держится, макрос стоит на `R`
(или крутится в петле `L…R`, если `L` раньше `R`); после `OFF` проигрывает шаги после `R`.
Пример огибающей громкости: `31 28 24 [R]20 12 6 0` — атака, удержание на 20, затухание после OFF.

Без петли макрос останавливается на последнем значении.

### Модуляция волны (wavetable)

Макрос **WAVE** — это и есть переключение волн на лету: значения — номера волн банка.
`SPD` задаёт, сколько тиков звучит каждая волна. Пример: значения `0 1 2 3`, `SPD 4`,
петля на шаге 0 → четыре волны по 4 тика по кругу. Волны создаются `CTRL+W`
(копия текущей) и рисуются в окне волны; `PGUP/PGDN` в фокусе волны — листать волны.
Каждое переключение — перезапись памяти волны канала (как на консоли, со щелчком),
поэтому очень частые смены (SPD 1) звучат «шершаво» — это поведение железа.
В паттерне то же делает эффект `Wxx`, но макрос не требует писать команду на каждой строке.

## DDA-семплы

**Перетащите .wav на окно** или нажмите `CTRL+I` (окно выбора файла) — файл станет
семплом текущего инструмента (тип DDA).
Конвертация повторяет возможности консоли: моно, частота таймера **~6991 Гц**, **5 бит**,
нормализация по пику, максимум 65535 значений (~9.4 с; реальный предел — место в ROM).

Высота: `C-4` — исходная скорость; другие ноты шагают по семплу с шагом 8.8 (как драйвер на 6280),
арпеджио тоже работает. Слайды/вибрато на DDA не действуют (у DDA нет периода).

### Чего нет и почему

- Разные частоты дискретизации для разных семплов — таймер один на систему.
- Семплы больше 5 бит, интерполяция, фильтры — не умеет железо.
- Отмена импорта семпла: данные семпла не входят в undo (экономия памяти);
  отменяется только назначение семпла инструменту.
