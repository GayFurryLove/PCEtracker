# Экран инструмента (F10)

`F9` — паттерны, `F10` — инструмент. `TAB` переключает фокус: параметры → волна → макрос.
Клавиши нот на этом экране всегда проигрывают текущий инструмент (инструменты с шумовым
макросом — на канале 5, где шум существует).

## Параметры

| Поле | Значения | Клавиши |
|---|---|---|
| NAME | имя (ASCII) | ENTER — ввод, ENTER/ESC — готово/отмена |
| TYPE | WAVETABLE / DDA SAMPLE | ENTER или ←/→ |
| WAVE | номер волны из банка | ←/→ (SHIFT ×16) |
| SAMPLE | номер DDA-семпла | ←/→ |
| VOLUME | 00-1F | ←/→ |
| PHASE | FREE RUNNING / RESET ON NOTE | ENTER |

`CTRL+N` новый инструмент, `CTRL+D` копия, `CTRL+W` новая волна (копия текущей),
`CTRL+T` название песни. Всё это отменяется `CTRL+Z`.

## Волна — 32 отсчёта × 5 бит

Ровно то, что лежит в памяти волны канала. ←/→ отсчёт, ↑/↓ значение (SHIFT ±4),
PGUP/PGDN — другая волна. Мышью можно рисовать.
`ALT+1…9`: синус, меандр, пила, треугольник, шум, очистить, инверсия, сдвиг фазы, половина амплитуды.

## Макросы

Одно значение на тик (60 Гц). ←/→ шаг, ↑/↓ значение (SHIFT ±8), INS/DEL вставить/удалить шаг,
`ALT+L` петля с этого шага, `ALT+R` точка release, `ALT+C` очистить, PGUP/PGDN — другой макрос.
Мышью можно рисовать. Подробно о смысле значений — [EFFECTS.md](EFFECTS.md).

## DDA-семплы

**Перетащите .wav на окно** — файл станет семплом текущего инструмента (тип DDA).
Конвертация повторяет возможности консоли: моно, частота таймера **~6991 Гц**, **5 бит**,
нормализация по пику, максимум 65535 значений (~9.4 с; реальный предел — место в ROM).

Высота: `C-4` — исходная скорость; другие ноты шагают по семплу с шагом 8.8 (как драйвер на 6280),
арпеджио тоже работает. Слайды/вибрато на DDA не действуют (у DDA нет периода).

### Чего нет и почему

- Разные частоты дискретизации для разных семплов — таймер один на систему.
- Семплы больше 5 бит, интерполяция, фильтры — не умеет железо.
- Отмена импорта семпла: данные семпла не входят в undo (экономия памяти);
  отменяется только назначение семпла инструменту.
