# PCEtracker — руководство

Трекер только для PC Engine / TurboGrafx-16. Всё, что вы слышите, — это звуковой чип
HuC6280 и то, что его драйвер может делать 60 раз в секунду. Ничего лишнего: если
консоль чего-то не умеет, этого нет и в трекере.

## Запуск

```bash
pcetracker song.pcet      # открыть (или создать, если файла нет)
pcetracker                # новая песня untitled.pcet
```

Два экрана: **F9 — паттерны**, **F10 — инструмент**. **F12** — все клавиши.

## Как устроена песня

- **6 каналов** — как у чипа. Каналы 5 и 6 умеют шум, любой канал — DDA-семплы,
  канал 2 может модулировать частоту канала 1 (LFO).
- **Паттерн** — до 256 строк на все 6 каналов. **Ордер** — последовательность паттернов.
- **Тик** = один кадр 59.826 Гц. **Скорость** = тиков на строку (`Fxx`). Темпа в BPM нет:
  драйвер консоли работает от кадрового прерывания.
- **Волна** — 32 отсчёта × 5 бит, ровно память волны канала.
- **Инструмент** — волна или DDA-семпл, громкость и макросы (значение на каждый тик).

## Экран паттернов

| Клавиши | Действие |
|---|---|
| `SPACE` | режим записи вкл/выкл (без него клавиши нот только проигрывают) |
| `Z S X D C V G B H N J M , L . ; /` | ноты, нижняя октава |
| `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` | ноты, верхняя октава |
| `1` | OFF (отпустить ноту) |
| `0-9 A-F` | цифры инструмента, громкости, параметра эффекта |
| буквы/цифры в колонке команды | команда эффекта |
| `DEL` / `INS` / `BACKSPACE` | очистить поле / вставить строку / удалить строку |
| стрелки, `PGUP/PGDN`, `HOME/END`, `TAB` | перемещение |
| `ENTER` / `SHIFT+ENTER` / `CTRL+ENTER` | играть песню или стоп / зациклить паттерн / играть с текущей строки |
| `ESC` | стоп, снять выделение |
| `F1/F2` октава, `F3/F4` инструмент, `F5/F6` шаг записи | |
| `CTRL+1…6` / `CTRL+SHIFT+1…6` | заглушить канал / соло |

Клавиши нот определяются **по положению на клавиатуре**, раскладка (в т.ч. русская) не важна.

### Блоки, отмена

`SHIFT+стрелки` — выделить, `CTRL+A` — канал (ещё раз — весь паттерн), `CTRL+C/X/V`,
`CTRL+↑/↓` — транспонировать (с `SHIFT` — на октаву), `CTRL+Z` / `CTRL+Y` — отмена/повтор.

### Ордер и паттерны

`CTRL+←/→` — позиция ордера, `CTRL+PGUP/PGDN` — номер паттерна в позиции,
`CTRL+INS/DEL` — вставить/удалить позицию, `CTRL+N` — новый пустой паттерн,
`CTRL+D` — копия паттерна, `ALT+↑/↓` (`ALT+PGUP/PGDN`) — длина паттерна,
`ALT+←/→` — скорость песни.

## Экран инструмента (F10)

Подробно — [INSTRUMENTS.md](INSTRUMENTS.md). Коротко: `TAB` — параметры / волна / макрос,
стрелки — правка, мышь — рисование волны и макросов, клавиши нот — прослушать.
**Перетащите .wav на окно** — получится DDA-семпл.

## Эффекты

Полный список — [EFFECTS.md](EFFECTS.md).

`0xy` арпеджио · `1xx/2xx` слайд · `3xx` портаменто · `4xy` вибрато · `8xy` панорама ·
`Axy` громкость · `Bxx` переход · `Cxx` обрезать · `Dxx` конец паттерна · `Fxx` скорость ·
`Gxy` общая громкость · `Lxx/Mxx` LFO · `Nxx` шум (кан. 5-6) · `Pxx` расстройка ·
`Rxx` повтор ноты · `Wxx` волна

## Файлы и экспорт

| Клавиши | Действие |
|---|---|
| `CTRL+S` / `CTRL+SHIFT+S` / `CTRL+O` | сохранить / сохранить как / открыть (путь вводится в строке внизу) |
| `CTRL+T` | название песни |
| `CTRL+E` | WAV рядом с песней |
| `CTRL+H` | HES (звуковой формат PC Engine) |
| `CTRL+R` | HuCard ROM `.pce` с экраном названия |

HES и ROM перед записью проверяются встроенной машиной HuC6280: файл появляется,
только если он воспроизводит ровно то, что звучит в трекере. Статус проверки в
эмуляторах и на железе — [EXPORT.md](EXPORT.md).

Из консоли то же самое:
```bash
pcet_render song.pcet song.wav --bits 24 --rate 96000 --hes song.hes --rom song.pce
```

## Настройки

Файл `pcetracker.cfg` создаётся при первом запуске
(Linux: `~/.local/share/pcetracker/pcetracker/`, Windows: `%APPDATA%\pcetracker\pcetracker\`).

| Параметр | Значение |
|---|---|
| `scale` | целый масштаб окна (1 = 1024×600) |
| `fullscreen` | `0`, `1` или `auto` (на весь экран, если окно не помещается) |
| `software_render` | `1` — без GPU |
| `vsync` | вертикальная синхронизация |
| `fps` | обновлений экрана в секунду при воспроизведении (на слабом CPU — 20 или 15) |
| `audio_rate`, `audio_buffer` | частота и буфер звука (если трещит — 2048 или 4096) |
| `revision` | `6280a` или `6280` — ревизия звукового чипа |

## Производительность

```bash
pcetracker songs/demo.pcet --benchmark
```
Печатает, сколько процессора занимают звук и отрисовка на этой машине.
Пример (десктоп, программный рендерер): звук 0.13 % ядра, отрисовка ~1.4 мс на кадр.
Окно без воспроизведения не перерисовывается вовсе; при воспроизведении — только
когда на экране что-то изменилось, не чаще `fps` раз в секунду.
