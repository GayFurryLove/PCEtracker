# PCEtracker — руководство

Трекер только для PC Engine / TurboGrafx-16. Всё, что вы слышите, — это звуковой чип
HuC6280 и то, что его драйвер может делать 60 раз в секунду. Ничего лишнего: если
консоль чего-то не умеет, этого нет и в трекере.

## Запуск

```bash
pcetracker song.pcet      # открыть (или создать, если файла нет)
pcetracker                # новая песня
```

Сначала показывается заставка с маскотом: закрывается любой клавишей или щелчком
(первые 0,7 с ввод не считается — чтобы ENTER из терминала её не «проглотил») или сама
через 3 с. Отключить: `demo=0` в `pcetracker.cfg` или `pcetracker --no-splash`.

Экраны: **F9 — паттерны**, **F10 — инструмент**, **F8 / F11 — ордеры и список паттернов**.
**F12** — справка по страницам (←/→ листать, 1–7 — сразу на страницу).

## Как устроена песня

- **6 каналов** — как у чипа. Каналы 5 и 6 умеют шум, любой канал — DDA-семплы,
  канал 2 может модулировать частоту канала 1 (LFO).
- **Паттерн** — до 256 строк на все 6 каналов. **Ордер** — последовательность паттернов.
- **Тик** = один кадр 59.826 Гц. **Скорость** = тиков на строку (`F01`–`F1F`).
  **Темп** (`F20`–`FE`, по умолчанию 150 = `F96`) растягивает строки: строка длится
  `скорость × 150 / темп` тиков. BPM-таймера у консоли нет — темп работает целыми кадрами.
- **Волна** — 32 отсчёта × 5 бит, ровно память волны канала.
- **Инструмент** — волна или DDA-семпл, громкость и макросы.

## Экран паттернов

| Клавиши | Действие |
|---|---|
| `SPACE` | режим записи вкл/выкл (без него клавиши нот только проигрывают; панель SONG показывает `EDIT`) |
| `Z S X D C V G B H N J M , L . ; /` | ноты, нижняя октава |
| `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` | ноты, верхняя октава |
| `1` | OFF (отпустить ноту) |
| `0-9 A-F` | цифры инструмента, громкости, параметра эффекта |
| буква/цифра в колонке команды | команда эффекта; курсор сразу переходит на две цифры параметра той же строки, после второй цифры возвращается в колонку команды строкой ниже |
| `DEL` | очистить **только поле под курсором** (нота, инструмент, громкость или эффект); если выделен блок — очистить блок |
| `BACKSPACE` / `INS` | удалить строку канала (нижние подтягиваются) / вставить пустую |
| стрелки, `PGUP/PGDN`, `HOME/END`, `TAB` | перемещение |
| `ENTER` | играть с текущего ордера / стоп |
| `F7` | играть песню **с самого начала** |
| `CTRL+ENTER` / `SHIFT+ENTER` | играть с текущей строки / зациклить паттерн |
| `ESC` | стоп, снять выделение |
| `F1/F2` октава, `F3/F4` инструмент, `F5/F6` шаг записи | |
| `CTRL+1…6` / `CTRL+SHIFT+1…6` | заглушить канал / соло |

Клавиши нот определяются **по положению на клавиатуре**, раскладка (в т.ч. русская) не важна.
Когда курсор стоит в колонке эффекта, строка состояния внизу объясняет этот эффект
(например `W05: NO SUCH WAVE…`, если такой волны в песне нет).

Панель **SONG** показывает скорость и темп, с которыми плеер играет **сейчас** (после `Fxx`
они меняются), и секундомер воспроизведения рядом с `PLAY`.

### Блоки, отмена

`SHIFT+стрелки` — выделить, `CTRL+A` — канал (ещё раз — весь паттерн), `CTRL+C/X/V`,
`DEL` — очистить блок, `CTRL+↑/↓` — транспонировать (с `SHIFT` — на октаву),
`CTRL+Z` / `CTRL+Y` — отмена/повтор.

### Ордер и паттерны с экрана паттернов

`CTRL+←/→` — позиция ордера, `CTRL+PGUP/PGDN` — номер паттерна в позиции,
`CTRL+INS/DEL` — вставить/удалить позицию, `CTRL+N` — новый пустой паттерн,
`CTRL+D` — копия паттерна, `ALT+↑/↓` (`ALT+PGUP/PGDN`) — длина паттерна,
`ALT+←/→` — скорость песни, `ALT+SHIFT+←/→` — темп песни.

## Экран ордеров (F8 или F11)

Слева — ордер-лист, в середине — все паттерны песни (длина, сколько раз стоит в ордере,
заполненность), справа — превью паттерна под курсором. Режим записи не нужен.

| Клавиши | Действие |
|---|---|
| `↑/↓`, `PGUP/PGDN`, `HOME/END`, мышь | выбрать позицию ордера |
| `0-9 A-F` | набрать номер паттерна позиции (цифры вдвигаются справа: `0`, `5` → `05`) |
| `+` / `-` | номер паттерна ±1 |
| `SHIFT+↑/↓` | передвинуть позицию вверх/вниз (переставить порядок) |
| `INS` / `DEL` | вставить копию позиции / удалить позицию |
| `CTRL+N` / `CTRL+D` | новый пустой паттерн / копия паттерна после позиции |
| `TAB` | переключиться между ордер-листом и списком паттернов |
| в списке паттернов: `ENTER` / `INS` | поставить паттерн в текущую позицию / добавить новой позицией |
| `F9` или двойной щелчок | редактировать паттерн этой позиции |
| `ENTER` (в ордер-листе) | играть с этой позиции / стоп |

## Экран инструмента (F10)

Подробно — [INSTRUMENTS.md](INSTRUMENTS.md) (там же — как ставить **петлю (loop)** макроса).
Коротко: `TAB` — параметры / волна / макрос, стрелки — правка, мышь — рисование волны и
макросов, клавиши нот — прослушать. **Перетащите .wav на окно** или `CTRL+I` — DDA-семпл.

## Эффекты

Полный список — [EFFECTS.md](EFFECTS.md).

`0xy` арпеджио (держится до `000`) · `Exx` скорость арпеджио · `1xx/2xx` слайд ·
`3xx` портаменто · `4xy` вибрато · `8xy` панорама · `Axy` громкость · `Bxx` переход ·
`Cxx` обрезать · `Dxx` конец паттерна · `Fxx` скорость/темп, `F00`/`FFF` — стоп песни ·
`Gxy` общая громкость · `Lxx/Mxx` LFO · `Nxx` шум (кан. 5-6) · `Pxx` расстройка ·
`Rxx` повтор ноты · `Wxx` волна

## Файлы и экспорт

| Клавиши | Действие |
|---|---|
| `CTRL+O` | загрузить песню |
| `CTRL+S` | сохранить (новая песня — спросит папку и имя) |
| `CTRL+SHIFT+S` | сохранить как |
| `CTRL+E` / `CTRL+H` / `CTRL+R` | экспорт WAV / HES / HuCard ROM `.pce` |
| `CTRL+I` | импорт .wav как DDA-семпл текущего инструмента |
| `CTRL+T` | название песни |

Все эти клавиши открывают **окно файлов**: сверху видно папку, ниже — подпапки и файлы
нужного типа. Стрелки/мышь — выбрать, `ENTER` или двойной щелчок — открыть папку/файл,
`BACKSPACE` — в родительскую папку (в Windows выше корня — список дисков), буква — прыжок
к файлу на эту букву. При сохранении и экспорте имя набирается в поле `FILE` (`TAB` или
стрелки — к списку); существующий файл перезаписывается только после второго `ENTER`.

Окно открывается в папке текущей песни, а для новой песни — в `song_dir` из конфига.
Новая песня получает имя из названия (`CTRL+T`): «My Song» → `my_song.pcet`,
без названия — `untitled.pcet`. Экспорт по умолчанию называется так же, как песня.

HES и ROM перед записью проверяются встроенной машиной HuC6280: файл появляется,
только если он воспроизводит ровно то, что звучит в трекере. Песня с `F00`/`FFF`
в экспорте заканчивается тишиной (без петли). Статус проверки в эмуляторах и на
железе — [EXPORT.md](EXPORT.md).

Из консоли то же самое:
```bash
pcet_render song.pcet song.wav --bits 24 --rate 96000 --hes song.hes --rom song.pce
```

## Настройки

Файл `pcetracker.cfg` ищется в таком порядке:
1. рядом с программой (переносная установка),
2. в папке, откуда трекер запущен,
3. в папке пользователя (Linux: `~/.local/share/pcetracker/pcetracker/`,
   Windows: `%APPDATA%\pcetracker\pcetracker\`) — создаётся там при первом запуске.

Какой файл реально прочитан — видно в справке (`F12`, страница 7 ABOUT) и в окне файлов.
Если в старом файле нет новых параметров, трекер сам дописывает их в конец с комментариями.
Пробелы вокруг `=` допустимы (`song_dir = ~/music`).

| Параметр | Значение |
|---|---|
| `scale` | целый масштаб окна (1 = 1024×600) |
| `fullscreen` | `0`, `1` или `auto` (на весь экран, если окно не помещается) |
| `software_render` | `1` — без GPU |
| `vsync` | вертикальная синхронизация |
| `fps` | обновлений экрана в секунду при воспроизведении (на слабом CPU — 20 или 15) |
| `audio_rate`, `audio_buffer` | частота и буфер звука (если трещит — 2048 или 4096) |
| `revision` | `6280a` или `6280` — ревизия звукового чипа |
| `demo` | `1` — заставка с маскотом при запуске, `0` — сразу в трекер |
| `song_dir` | папка, в которой открывается окно файлов для новой песни; туда же сохраняются новые песни. `~` — домашняя папка. Пусто — папка запуска |

## Производительность

```bash
pcetracker songs/demo.pcet --benchmark
```
Печатает, сколько процессора занимают звук и отрисовка на этой машине.
Пример (десктоп, программный рендерер): звук 0.13 % ядра, отрисовка ~1.4 мс на кадр.
Окно без воспроизведения не перерисовывается вовсе; при воспроизведении — только
когда на экране что-то изменилось, не чаще `fps` раз в секунду.
