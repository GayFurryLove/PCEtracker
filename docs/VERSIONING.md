# Версии

Версия задаётся в одном месте — `project(PCEtracker VERSION X.Y.Z)` в `CMakeLists.txt`.
CMake генерирует из неё `version.h` (`PCE_VERSION`), её видно в заголовке окна,
в `pcetracker --version` и в справке `pcet_render`.

## Правило

- **Этап / заметная фича** → поднять минор: `0.8.x` → `0.9.0`.
- **Исправление, мелкая правка** → поднять патч: `0.9.0` → `0.9.1`.
- `1.0.0` — когда экспорт проверен на железе и формат проекта заморожен.

Коммит, который меняет версию, получает тег:

```bash
git commit -m "v0.9.0: <что сделано>"
git tag -a v0.9.0 -m "v0.9.0: <что сделано>"
git push origin main --tags
```

Формат файла `.pcet` версионируется отдельно (`kFormatVersion`, см. [FORMAT.md](FORMAT.md)):
его поднимают только при несовместимом изменении формата.
